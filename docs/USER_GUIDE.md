# User guide
- **Students**: Add, search/filter, import CSV/Excel (download the template; rejected rows are listed), export Excel/CSV/PDF, open a profile for history, promote/transfer/graduate/withdraw/re-admit.
- **ID Cards**: pick a class chip (or search one student), tick students, choose front/back, theme and size, then Print or Export PDF. QR encodes admission no. and name.
- **Class Register**: choose class/date, mark, save. **Exams & Results**: create exam, enter marks per subject, view class ranking and report cards. Grades follow Settings → Grading system.
- **Fees & Payments**: Invoices (from fee structure) → Payments (receipt numbers are automatic) → Arrears. Entries are never edited; use *Reverse* with a reason.
- **Duty Roster**: weekly view; Generator previews a fair roster (nothing saved until Publish); conflicts with duties, lessons or approved leave are flagged; managers may override. Staff confirm/complete duties and request swaps; a deputy/head/admin approves.
- **Portals**: parent and student accounts see only linked records.
- **Admin**: Settings (school info, ID card, duty rules, grading), Users (create accounts; link parents to children by editing the user's `children` in the database or API for now), Audit Logs.
